# Support

## Getting help

- Read `README.md` for usage, configuration, and troubleshooting.
- Run `games-library.cmd -Help` for built-in help.
- Check `agents/context/known-issues.md` for known quirks.

## Reporting issues

Open an issue in the GitHub repository. Include:

- Windows version and PowerShell version (`$PSVersionTable`).
- The command you ran and the full output.
- Whether the issue is reproducible with `-DryRun`.
- Relevant config (remove secrets first).

## Security issues

See `SECURITY.md`. Do not open public issues for security vulnerabilities.
