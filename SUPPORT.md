# Support

## Getting help

If you need help using Games Library Manager:

1. **Read the documentation**
   - [README.md](README.md)
   - [User documentation](docs/user/README.md)
   - [Developer documentation](docs/developer/README.md)
2. **Check troubleshooting guidance**
   - [docs/user/troubleshooting.md](docs/user/troubleshooting.md)
3. **Search existing issues** for similar reports or questions (if using a hosted repository).

## Reporting bugs and requesting features

- **Bugs:** Use the bug report issue form and include reproduction steps, environment details, and sanitized logs.
- **Feature requests:** Use the feature request issue form and describe the problem/use case and proposed solution.
- **Security issues:** Follow [SECURITY.md](SECURITY.md). Do **not** report vulnerabilities publicly.

## What to include

To help diagnose issues quickly, include:

- Windows version
- WebView2 Runtime version (if known)
- App version/build or commit (if known)
- Affected storefront/provider(s)
- Relevant settings (library root, launcher overrides, etc.) with **no secrets/API keys**
- Exact steps to reproduce and expected vs actual behavior
- Sanitized error messages or logs (e.g. `crash.txt` if generated)

## Out of scope

Project maintainers may be unable to provide support for:

- Third-party storefront clients, APIs, or metadata services and their outages/changes
- Game-specific compatibility or DRM/licensing issues
- Custom modifications not part of the supported codebase
- Recovery of lost local data outside the app’s documented storage locations

## Community expectations

Please be respectful and follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) when asking for help or participating in discussions.
