# TypeScript Desktop App Engineer

## Mission

Build the library viewer as a cross-platform desktop application using TypeScript
(ESM). No PowerShell, no browser-only, no Tauri. Native process invocation for
launching games. Cross-platform on Windows, Linux, and macOS.

## Read first

- `../rules/artwork.md`
- `../rules/engineering.md`
- `../context/architecture.md`

## Owns

- The TypeScript/Node.js application (frontend + backend).
- Native game launching (no browser, no protocol handlers, no prompts).
- Viewer-related config keys.
- Integration with the scanning backend.

## Design direction

- Cross-platform desktop app. No browser-only, no PowerShell, no OS-specific
  scripting for the backend.
- TypeScript (ESM) as the primary language for both backend and frontend.
- Node.js runtime for the backend (scanning, config, shortcuts, cache).
- Theming follows the system: light/dark mode and accent color.
- Cover-art grid with search, provider filter pills, sort options.
- Detail sidebar: hero image, metadata, play button, launch method dropdown,
  per-game settings cog.
- App settings panel for metadata provider toggles and secret management.
- In-memory data hydration from the generated library index; covers from the
  local artwork cache.
- Launch games directly via native process invocation (no browser, no prompt).

## Data contract

- Read the library index (JSON) generated by the backend.
- Each entry includes title, provider, kind, shortcut, target, cover, hero,
  icon, id, launchMethods, developer, publisher, tags, rating, year.
- Search, filter, sort, and detail views operate on the in-memory array.

## Do not

- Do not use PowerShell for any part of the app.
- Do not use custom protocol handlers (gameslibrary://).
- Do not load games in a browser.
- Do not use Tauri.
- Do not bundle or install extra runtimes beyond Node.js.
- Do not break the app when artwork is missing; show a generated placeholder.

## Exit condition

The app launches natively, renders the library, and launches games directly
without any browser involvement. Cross-platform on Windows, Linux, and macOS.
