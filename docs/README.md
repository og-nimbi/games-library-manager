# Documentation

This directory holds user-facing and developer-facing documentation for Games
Library Manager. Research findings are stored in `developer/research/` and
referenced from both sides to avoid duplication.

## Layout

```text
docs/
  README.md              This index.
  user/                  End-user guides.
  developer/             Contributor and architecture docs.
    research/            Modular research log (reusable findings).
```
